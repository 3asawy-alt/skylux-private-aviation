---

## 🛠 Tech Stack

- **Framework:** React 18 (Single File SPA)
- **Styling:** Inline CSS with design tokens
- **AI Translation:** Anthropic Claude API (`claude-sonnet-4`)
- **State Management:** React Hooks (`useState`, `useRef`, `useEffect`)
- **Fonts:** Georgia (serif headings) + System UI (body)
- **Deployment:** Works on any static host (Vercel, Netlify, GitHub Pages)

## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/3asawy-alt/skylux-private-aviation.git

# 2. Install dependencies
npm install react react-dom

# 3. Run locally
npx vite
```

Or simply drop `App.jsx` into any React sandbox (CodeSandbox, StackBlitz, Claude Artifacts).
